# Sticker Collage Video Skill

A reusable Codex skill for creating editable, story-led sticker-collage videos from talking-head footage, narration, screenshots, screen recordings, logos, mascots, and reference videos.

## What it covers

- Transcript-synchronized visual planning
- Speaker-led, visual-only, and demonstration scenes
- Consistent physical sticker treatment for every foreground element
- Screenshot, screen-recording, and relationship-diagram composition
- Restrained sticker motion and interaction
- Three-pass review for meaning, layout, and playback quality

## Installation

Clone this repository into your Codex skills directory:

```bash
git clone https://github.com/Yangtze-Seventh/sticker-collage-video-skill.git ~/.codex/skills/sticker-collage-video
```

## Usage

```text
Use $sticker-collage-video to turn my talking-head footage, screenshots, and screen recordings into an editable animated sticker-collage video.
```

The skill treats the spoken audio as the timing anchor, keeps the timeline editable, and requires rendered-pixel and playback verification before delivery.
